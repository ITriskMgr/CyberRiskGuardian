# Jeu de références en français — en attente / French reference set — pending

**FR.** Ce dossier recevra le texte français du manuel *Introduction à la gouvernance de la cybersécurité* (Marc-André Léger,
3e éd., v2.51b), découpé comme le jeu anglais de `../references/` : un fichier par chapitre (`ch01-…` à `ch21-…`), les pages
liminaires (`00-…`), l'annexe sur CyberRiskGuardian, le corrigé des questions à choix multiples, les références et la
bibliographie, chacun commençant par sa ligne de citation.

Il est vide pour l'instant : il attend la source française v2.51b fournie par l'auteur. Le texte ne doit **pas** être produit
par traduction automatique du jeu anglais. D'ici là, la compétence `cybersecurity-governance` répond aux questions en français
à partir du texte anglais et indique que la citation est traduite.

**EN.** This folder will hold the French text of the textbook (3rd ed., v2.51b), split like the English set in `../references/`:
one file per chapter, the front matter, the CyberRiskGuardian appendix, the multiple-choice answer key, the references and
the bibliography, each starting with its citation line. It is empty until the author supplies the French v2.51b source; it
must not be produced by machine translation of the English set.
