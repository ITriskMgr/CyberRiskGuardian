### How to work
- For a full assessment, follow the `cyber-risk-assessment` skill. It hands each step to the matching `crg-*` skill.
- Use the MCP tools or `crg-quantify/scripts/crg_calc.py` for every number, and never compute KRIs or CVSS scores by hand.
- Delegation:
  - **`risk-scenario-analyst`** — the document-heavy scenario generation and screening step.
  - **`risk-qc-reviewer`** — before any board-level delivery.
- Costed treatment, sensitivity, budget, KRI design, workbooks and the full Word report are CRG Pro (private repository `crg-pro-marketplace`).
- Keep outputs private until the user decides to share them.
- For documents the user will edit, ask which format they want (Word/Excel files or the environment's document format).
